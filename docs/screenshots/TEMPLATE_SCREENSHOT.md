# Template and Guidelines for Screenshots / GIFs

ضع لقطات الشاشة وملفات GIF هنا. استخدم هذه القواعد لتسمية الملفات وتنظيمها:

- Naming convention:
  - `01_login.png`
  - `02_ai_predict.gif`
  - `03_book_appointment.png`

- Resolution: 1280x720 أو 1366x768 (أفقي)
- GIFs: قصّرها إلى 8-12 ثوانٍ، أعدّها إلى 15-20 FPS لتقليل الحجم.
- أدوات مقترحة: ShareX (Windows), Peek (Linux), ScreenToGif (Windows)

Tips:
- اجعل خلفية المتصفح نظيفة وخطوات واضحة.
- أضف تسميات قصيرة (overlay) لشرح الخطوات عند الحاجة.

عند إضافة صور، حدّث `README.md` لعرض الصورة المناسبة في القسم "Screenshots & GIFs".
